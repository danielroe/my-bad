# my-bad documentation

These pages cover `my-bad` in more depth than the [project README](../README.md). Start with a guide that matches your setup, then use the reference pages when you need the details.

## Guides

- [Integrate with a dev server](./dev-server.md): build reports, publish them to the live channel, and add the badge to every page.
- [Use with Vite](./vite.md): configure the Vite plugin, render server errors, and add the Vite DevTools dock.
- [Publish problems](./problems.md): show diagnostics from a type checker, linter, or audit on every page.

## Reference

- [Reports](./reports.md): what `createReport` reads from an error, its options, source loaders, compile errors, and presets.
- [Rendering](./rendering.md): the error page, overlay, badge, terminal output, Markdown and JSON, and theming.
- [Live channel](./channel.md): channel options, routes, access rules, publishing methods, and sinks.
- [API](./api.md): every export of each entry point.
